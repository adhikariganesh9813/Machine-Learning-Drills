# Python DSA & Algorithms

A collection of Data Structures, Algorithms, and Machine Learning scripts implemented in Python.

## Contents
- **Linear Regression (`linear_regression_algorithm.py`)**: A from-scratch implementation of a simple linear regression algorithm predicting house prices using a custom square trick.
- **Selection Sort (`selection_sort.py`)**: Implementation of the selection sort algorithm.
- **Dijkstra's Algorithm (`dijkstra's_algorithm.py`)**: Graph routing and shortest-path algorithm.
- Miscellaneous practice scripts (`prac.py`, `prac2.py`).
